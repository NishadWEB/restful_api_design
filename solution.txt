RESTful API Design – Tasks Resource

1. RESOURCE INFORMATION

Resource: Task

Base URL: https://api.example.com

Endpoint: /tasks

Task JSON Structure:

{
    "id": 101,
    "title": "Learn Django",
    "completed": false
}

Field descriptions:
- id: Unique task identifier (integer).
- title: Task name (string, required).
- completed: Task completion status (boolean).


2. API ENDPOINTS

2.1 GET /tasks

Description: Retrieve all tasks.

Query Parameters:
- page: Page number.
- limit: Number of tasks per page.
- completed: Filter tasks by completion status.

Example:
GET /tasks?page=1&limit=10&completed=false

Status: 200 OK

Response:

{
    "count": 2,
    "next": null,
    "previous": null,
    "results": [
        {
            "id": 101,
            "title": "Learn Django",
            "completed": false
        }
    ]
}


2.2 GET /tasks/{id}

Description: Retrieve a specific task using its ID.

Example:
GET /tasks/101

Status: 200 OK

Response:

{
    "id": 101,
    "title": "Learn Django",
    "completed": false
}

Error: 404 Not Found - Task does not exist.


2.3 POST /tasks

Description: Create a new task.

Request Body:

{
    "title": "Learn REST API",
    "completed": false
}

Status: 201 Created

Response:

{
    "id": 102,
    "title": "Learn REST API",
    "completed": false
}

Error: 400 Bad Request - Invalid or missing fields.


2.4 PUT /tasks/{id}

Description: Completely replace an existing task.

Example:
PUT /tasks/101

Request Body:

{
    "title": "Learn Django REST Framework",
    "completed": true
}

Status: 200 OK

Response:

{
    "id": 101,
    "title": "Learn Django REST Framework",
    "completed": true
}

Errors:
- 400 Bad Request - Invalid or missing fields.
- 404 Not Found - Task does not exist.


2.5 PATCH /tasks/{id}

Description: Partially update an existing task.

Example:
PATCH /tasks/101

Request Body:

{
    "completed": true
}

Status: 200 OK

Response:

{
    "id": 101,
    "title": "Learn Django",
    "completed": true
}

Errors:
- 400 Bad Request - Invalid field values.
- 404 Not Found - Task does not exist.


2.6 DELETE /tasks/{id}

Description: Delete a specific task using its ID.

Example:
DELETE /tasks/101

Status: 204 No Content

No response body is returned.

Error: 404 Not Found - Task does not exist.



3. HTTP STATUS CODES

200 OK: Request successful.

201 Created: Resource successfully created.

204 No Content: Resource successfully deleted.

400 Bad Request: Invalid request data.

404 Not Found: Requested resource does not exist.
